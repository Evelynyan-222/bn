# Inner Weather

When someone selects a mood, the experience should turn that feeling into a type of weather. I wanted to make a simple experience that connects emotions with weather because I think weather can sometimes feel similar to our moods. I chose four moods: Calm, Happy, Tired, and Overwhelmed. Calm has soft clouds and a beam of morning light, Happy feels like a bright sunrise, Tired is gray and foggy, and Overwhelmed is dark and rainy. I used Codex to help me turn this idea into HTML, CSS, and JavaScript.

When I tested the first version, everything worked, but some of the visuals did not feel right to me. Calm and Tired looked too similar, and Happy looked more like a yellow gradient than a real sunrise. I asked Codex to make Calm feel cozier with clouds and one clear beam of light, make Tired more gray and foggy, and give Happy more realistic sunrise colors. Then I tested the moods again to see if they felt more different from each other. This made me realize that AI can help me build things quickly, but I still need to decide what looks right, what does not work, and how I want to change it. If I kept working on this, I would like to add more moods and let people create their own connections between emotions and weather. To run the project, open index.html in a browser. One prompt I used with Codex was to make Calm feel cozier with clouds and one clear beam of light, make Tired grayer and foggier, and give Happy more realistic sunrise colors.
